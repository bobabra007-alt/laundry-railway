Обновление: траты и iPhone

Ничего вручную в коде менять не нужно.

  1. Распакуйте архив.
  2. Откройте существующий репозиторий laundry-railway на GitHub.
  3. Add file → Upload files: загрузите содержимое распакованной папки в корень репозитория, включая src, prisma и остальные вложенные папки. Сам ZIP не загружайте.
  4. Commit changes в main. Дождитесь успешного запуска Railway и обновите сайт.

База и переменные остаются прежними. Команда запуска — npm start. Новый раздел «Траты» появится автоматически, как и мобильное меню на iPhone.

Обновление уже работающей CRM

  1. В существующем GitHub-репозитории откройте Add file → Upload files. Перетащите всё содержимое этого распакованного архива в корень и сохраните через Commit changes. Не создавайте новую базу и не меняйте переменные Railway.
  2. В Railway оставьте Start Command npm start. Дождитесь завершения автоматического Deploy.
  3. В Deploy Logs должна появиться строка Employee shares verified: fixed split between four people. После этого обновите страницу CRM.

С прибыли 500 USDT компания получает 375, общий банк сотрудников — 125, каждому из четырёх — 31,25. Старые завышенные начисления корректируются дополнительными записями; подтверждённые выплаты сохраняются.

Если участников ещё меньше четырёх, остальные доли ждут назначения. Создайте сотрудников в разделе «Пользователи» и включите участие в банке. В новый архив входят все старые миграции и одна новая — таблицы не удаляются.

Laundra

Запуск через браузер на Windows. Без терминала и редактирования кода.

Нужны только GitHub и Railway. Vercel и Neon не используются. В саму CRM сотрудники входят по обычному логину и паролю.

Шаг 1

Загрузите проект на GitHub

  1. Откройте создание репозитория GitHub.
  2. Название: laundra-railway. Выберите Private и включите Add README. Нажмите Create repository.
  3. В репозитории нажмите Add file → Upload files.
  4. В папке распакованного проекта выделите все файлы и папки внутри и перетащите на страницу GitHub. Сам ZIP загружать не нужно.
  5. Нажмите Commit changes. Проверьте, что package.json, vercel.json, src и prisma видны сразу в корне репозитория.

Архив уже содержит только нужные файлы. Здесь нет паролей, базы данных и установленных зависимостей.

Шаг 2

Создайте проект и базу в Railway

  1. Откройте Railway, нажмите New Project → Empty Project.
  2. Внутри проекта нажмите + New → Database → PostgreSQL.
  3. Дождитесь запуска сервиса PostgreSQL. База останется внутри этого проекта.
  4. В том же проекте нажмите + New → GitHub Repo. Подключите GitHub и выберите laundra-railway.

На схеме проекта появятся два отдельных блока: PostgreSQL и приложение Laundra. Переменные следующего шага добавляйте в блок приложения, а не в PostgreSQL.

Шаг 3

Подготовьте секрет и пароль

Эта страница создаёт случайные значения в вашем браузере. Она не отправляет их в сеть и не сохраняет. Перенесите их в поля Railway и сохраните пароль в своём менеджере паролей.

Можно заменить пароль своим: минимум 12 символов, максимум 72 байта UTF-8. Логин администратора — admin.

При обновлении этой страницы случайные значения поменяются. Секрет приложения храните в Railway; пароль сохраните до закрытия страницы.

Шаг 4

Настройте приложение

  1. Откройте блок приложения и вкладку Variables.
  2. Добавьте Reference Variable: выберите сервис PostgreSQL и его значение DATABASE_URL. Название переменной в приложении должно быть DATABASE_URL. Так Railway автоматически свяжет приложение с базой; пароль базы копировать не нужно.
  3. Добавьте AUTH_SECRET и ADMIN_PASSWORD: значения скопируйте из шага 3.
  4. Примените изменения кнопкой Deploy / Deploy changes. Если приложение пыталось запуститься до добавления переменных, просто запустите новый Deploy после их сохранения.
  5. Дождитесь успешного запуска приложения. Затем откройте Settings → Networking → Public Networking → Generate Domain.
  6. Откройте полученный адрес. Логин: admin. Пароль: значение ADMIN_PASSWORD.
Сборка и запуск заданы в проекте. Перед запуском приложение автоматически применяет миграции и создаёт первого администратора. При перезапуске данные и существующий пароль сохраняются. Изменить пароль можно в разделе Мой профиль.

Если Railway запрашивает target port для домена, используйте порт из строки запуска в Deploy Logs (Ready / Local). Приложение слушает назначенный Railway PORT.

После входа

Создайте аккаунты сотрудников

Откройте Пользователи. Задайте каждому имя, логин, пароль и права галочками. Участие в банке сотрудников включайте только тем, кто получает долю прибыли.

Создайте тестового клиента, партнёра и сделку. Проверьте права и расчёты до внесения реальных данных. Подтверждение выплат доступно сотруднику в день выплаты.

Вложения уже подключены

Файлы до 2 МБ сохраняются в PostgreSQL. В карточке клиента или сделки можно загрузить и скачать файл. Скачивание доступно только вошедшим активным пользователям CRM.

Отдельный аккаунт или хранилище не нужны. Файлы занимают место в базе Railway и входят в её расходы на хранение.

Если Deploy завершился ошибкой, откройте Build Logs и пришлите текст ошибки. Не отправляйте строку подключения, секрет приложения и пароли.
