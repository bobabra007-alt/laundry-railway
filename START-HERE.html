Laundra

Запуск через браузер на Windows. Без терминала и редактирования кода.

Нужны аккаунты GitHub, Neon и Vercel. В саму CRM сотрудники входят по обычному логину и паролю.

Шаг 1

Загрузите проект на GitHub

  1. Откройте создание репозитория GitHub.
  2. Название: laundra. Выберите Private и включите Add README. Нажмите Create repository.
  3. В репозитории нажмите Add file → Upload files.
  4. В папке распакованного проекта выделите все файлы и папки внутри и перетащите на страницу GitHub. Сам ZIP загружать не нужно.
  5. Нажмите Commit changes. Проверьте, что package.json, vercel.json, src и prisma видны сразу в корне репозитория.

Архив уже содержит только нужные файлы. Здесь нет паролей, базы данных и установленных зависимостей.

Шаг 2

Создайте базу в Neon

  1. Откройте Neon и создайте проект laundra.
  2. Нажмите Connect. Выключите Connection pooling.
  3. Скопируйте строку подключения, начинающуюся с postgresql://, целиком. Она понадобится для поля DATABASE_URL в Vercel.

На этом шаге не нужно создавать таблицы или запускать SQL. Приложение подготовит их при первом production-деплое.

Шаг 3

Подготовьте секрет и пароль

Эта страница создаёт случайные значения в вашем браузере. Она не отправляет их в сеть и не сохраняет. Перенесите их в поля Vercel и сохраните пароль в своём менеджере паролей.

Можно заменить пароль своим: от 12 до 72 символов. Логин администратора — admin.

При обновлении этой страницы случайные значения поменяются. Секрет приложения храните в Vercel; пароль сохраните до закрытия страницы.

Шаг 4

Разместите CRM на Vercel

  1. Откройте Vercel → New Project, подключите GitHub и импортируйте репозиторий laundra.
  2. Framework: Next.js. Остальные настройки сборки оставьте как есть. В проекте уже задана версия Node.js 24.
  3. Разверните Environment Variables и добавьте три поля: DATABASE_URL — строка из Neon; AUTH_SECRET — секрет из шага 3; ADMIN_PASSWORD — пароль из шага 3. Убедитесь, что они включены для Production.
  4. Нажмите Deploy и дождитесь статуса Ready.
  5. Откройте production-адрес приложения. Логин: admin. Пароль: значение ADMIN_PASSWORD.
При production-деплое автоматически применяются миграции и создаётся первый администратор. На повторных деплоях существующие данные и пароль сохраняются. Изменить пароль можно в разделе Мой профиль.
После входа

Создайте аккаунты сотрудников

Откройте Пользователи. Задайте каждому имя, логин, пароль и права галочками. Участие в банке сотрудников включайте только тем, кто получает долю прибыли.

Создайте тестового клиента, партнёра и сделку. Проверьте права и расчёты до внесения реальных данных. Подтверждение выплат доступно сотруднику в день выплаты.

Вложения — отдельный необязательный шаг

Для файлов откройте проект Vercel → Storage → Create Storage → Blob. Выберите Private и подключите хранилище к проекту. Для установленной версии SDK нужен BLOB_READ_WRITE_TOKEN; если он не добавлен автоматически, скопируйте его из настроек Blob в Environment Variables проекта. Затем сделайте Redeploy.

Без Blob CRM запускается, но загрузка файлов недоступна. В этой версии скачивание приватных вложений ещё требует доработки.

Если Deploy завершился ошибкой, откройте Build Logs и пришлите текст ошибки. Не отправляйте строку подключения, секрет приложения и пароли.
