ОБНОВЛЕНИЕ СУЩЕСТВУЮЩЕГО LAUNDRA 0.2 → 0.3

Это только изменённые и новые файлы. Остальные уже находятся в вашем репозитории.
1. Сделайте резервную копию Postgres в Railway → Backups.
2. Распакуйте этот ZIP через «Извлечь всё».
3. В существующем репозитории GitHub откройте корень, где находится package.json.
4. Add file → Upload files. Перетащите содержимое распакованной папки: файлы и папки src, prisma, tests. Сам ZIP и внешнюю папку не загружайте.
5. Дождитесь окончания загрузки всех файлов и нажмите Commit changes один раз.
6. Дождитесь обновления Railway. Не меняйте Variables и не удаляйте старые файлы или базу.

Если ошибка появляется даже на одном файле, проблема не в числе файлов: попробуйте другой браузер без расширений. Если не поможет, пришлите скриншот ошибки без паролей.
Подробности обновления: UPDATE-OCT16.html.
